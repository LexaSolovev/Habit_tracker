# Habit Tracker

SPA веб-приложение для трекинга полезных привычек, основанное на принципах книги Джеймса Клира "Атомные привычки".

## 📖 О проекте

Бэкенд-часть SPA приложения для создания и отслеживания привычек. Позволяет пользователям создавать полезные привычки, устанавливать напоминания и получать уведомления через Telegram.

## 🚀 Быстрый старт

### Установка

```bash
# Клонирование репозитория
git clone <repository-url>
cd habit_tracker

# Создание виртуального окружения
python -m venv venv

# Активация окружения
# Linux/macOS:
source venv/bin/activate
# Windows:
venv\Scripts\activate

# Установка зависимостей
pip install -r requirements.txt
```
